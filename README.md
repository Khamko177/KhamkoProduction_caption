# Khamko Production - Meme & Caption Image Generator 💬✨

Trình tạo ảnh Caption & Meme theo phong cách thông báo iOS / Messenger cho **Khamko Production**.

## 🌟 Tính Năng
- ✍️ **Live Preview thời gian thực**: Gõ chữ đến đâu hình ảnh hiển thị ngay tới đó.
- 🇱🇦 **Hỗ trợ đa ngôn ngữ**: Tiếng Lào (Noto Sans Lao), Tiếng Việt có dấu, Tiếng Anh và Emoji (🫠, 🫣, 😂...).
- 📥 **Xuất ảnh HD**: Tải file ảnh chuẩn HD (1284x900px) sắc nét.
- 📋 **Copy to Clipboard**: Sao chép ảnh để paste ngay lên Facebook / Zalo (`Ctrl + V`).
- ⚡ **Presets**: Danh sách các mẫu meme kinh điển và thanh emoji chọn nhanh.

## 🚀 Hướng dẫn cài đặt & Chạy ứng dụng

### 1. Cài đặt thư viện:
```bash
npm install
```

### 2. Chạy máy chủ phát triển (Dev Server):
```bash
npm run dev
```
Hoặc nhấp đúp vào file `start.bat` trên Windows.

### 3. Build sản phẩm:
```bash
npm run build
```
